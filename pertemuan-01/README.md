1.Apa yang dimaksud dengan konsep dasar pemrograman web?
Jawaban:
Pemrograman web adalah proses membuat dan mengembangkan website atau aplikasi yang dapat diakses melalui internet. 
Dalam pemrograman web terdapat beberapa teknologi yang digunakan untuk membuat struktur, tampilan, interaksi, serta mengolah dan menyimpan data pada website.

⁠2.Apa yang dimaksud dengan arsitektur klien-peladen (client-server)?
Jawaban:
Arsitektur klien-peladen adalah sistem di mana clientdan server saling berkomunikasi. Client adalah perangkat yang digunakan oleh pengguna, seperti HP atau laptop, sedangkan server adalah komputer yang menyediakan dan mengolah data. Contohnya, ketika kita membuka sebuah website, browser pada HP meminta data kepada server, kemudian server mengirimkan data tersebut kembali ke browser.
Sederhananya client meminta data, sedangkan server menyediakan data.

3. Apa yang dimaksud dengan HTTP Request dan HTTP Response?
Jawaban:
HTTP Request adalah permintaan yang dikirim oleh client atau browser kepada server untuk meminta suatu data atau halaman website.
Sedangkan HTTP Response adalah jawaban yang diberikan oleh server kepada client setelah menerima request.

5. Apa fungsi HTML, CSS, JavaScript, PHP, dan MySQL dalam pemrograman web?
Jawaban:
Masing-masing teknologi memiliki fungsi yang berbeda:
* HTML digunakan untuk membuat struktur atau isi website, seperti judul, teks, gambar, dan tombol.
* CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran tulisan, dan tata letak.
* JavaScript digunakan untuk membuat website menjadi lebih interaktif, seperti tombol, menu, dan fitur lainnya.
* PHP digunakan untuk menjalankan proses pada server, misalnya mengolah data yang dikirim oleh pengguna.
* MySQL digunakan untuk menyimpan dan mengelola data, seperti data pengguna, produk, atau informasi lainnya.

5. Bagaimana hubungan antara HTML, CSS, JavaScript, PHP, dan MySQL?
Jawaban:
HTML, CSS, JavaScript, PHP, dan MySQL dapat bekerja sama dalam membuat sebuah website.
HTML membuat struktur website,CSS mengatur tampilannya,JavaScript membuat website menjadi interaktif. Sementara itu, PHP dapat digunakan untuk memproses data di server, dan MySQL digunakan untuk menyimpan data.

Contohnya pada website toko online. HTML menampilkan produk, CSS membuat tampilannya menarik, JavaScript mengatur interaksi pengguna, PHP memproses pesanan, dan MySQL menyimpan data produk serta pesanan.
