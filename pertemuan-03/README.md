# Pertemuan 3 - Formulir HTML dan CSS Dasar
## Baseline
- Menggunakan hasil P2 sebagai dasar pengembangan P3.
- Menyalin `index.html` dan `img/foto-profil.jpg` ke `pertemuan-03/`.

## Implementasi Formulir
- Elemen form yang digunakan: [form, label, select, input, textarea, button, option]
- Tipe input yang digunakan: text, email, password, number, dan submit.
- Atribut validasi yang digunakan: required, minlength, maxlength, min, dan max.

## Pengujian GET dan POST
- Hasil pengujian GET: Data formulir berhasil dikirim melalui URL dan dapat dilihat pada bagian query string.
- Contoh URL encoding yang ditemukan:  spasi diubah menjadi %20 atau +, sedangkan karakter khusus seperti @ dapat diubah menjadi %40.
- Hasil pengujian POST: [dapat digunakan]Data berhasil dikirim dan tidak ditampilkan pada URL sehingga metode POST dapat digunakan untuk mengirim data formulir.

## CSS Dasar

- Selector elemen: body, form, input, button, dan label.
- Selector class: .container, .form-group, dan .btn.
- Selector ID: #nama, #email, dan #formulir.
- Properti CSS dasar yang digunakan: color, background-color, font-family, font-size, margin, padding, width, border, border-radius, dan text-align


## Pengujian dan Perbaikan
- Galat yang ditemukan: Beberapa data formulir belum dapat dikirim dengan benar dan tampilan form belum tertata dengan baik.
- Penyebab galat: Terdapat atribut form yang belum sesuai serta beberapa selector CSS belum diterapkan pada elemen yang tepat.
- Perbaikan yang dilakukan: Memperbaiki atribut action dan method, menambahkan atribut validasi yang diperlukan, serta memperbaiki selector dan properti CSS.
- Hasil pengujian ulang: Formulir berhasil digunakan, data dapat dikirim menggunakan metode GET maupun POST, dan tampilan halaman menjadi lebih rapi.
