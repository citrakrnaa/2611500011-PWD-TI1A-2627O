# Pertemuan 3 - Formulir HTML dan CSS Dasar

## Baseline
- Menggunakan hasil P2 sebagai dasar pengembangan P3.
- Menyalin `index.html` dan `img/foto-profil.jpeg` ke `pertemuan-03/`.

## Implementasi Formulir
- Elemen form yang digunakan: `<form>`, `<label>`, `<input>`, `<select>`, `<option>`, `<textarea>`, dan `<button>`.
- Tipe input yang digunakan: `text`, `email`, `number`, `radio`, dan `checkbox`.
- Atribut validasi yang digunakan: `required`, `minlength`, `maxlength`, `placeholder`, `min`, dan `max`.

## Pengujian GET dan POST
- Hasil pengujian GET: Formulir menggunakan metode GET untuk mengirimkan data melalui URL browser.
- Contoh URL encoding yang ditemukan: `nama=Citra&email=2611500011@mahasiswa.atmaluhur.ac.id&semester=1`.
- Hasil pengujian POST: Belum diterapkan karena formulir masih menggunakan metode GET (`method="get"`).

## CSS Dasar
- Selector elemen: Belum dapat dipastikan dari kode yang dikirim.
- Selector class: `.form-group` dan `.input-form`.
- Selector ID: `#tentang`, `#keahlian`, `#contact`, `#nama`, `#email`, dan `#semester`.
- Properti CSS dasar yang digunakan: Perlu disesuaikan dengan isi file CSS yang diterapkan.

## Pengujian dan Perbaikan
- Galat yang ditemukan: Struktur formulir perlu diperiksa kembali agar setiap elemen memiliki pasangan label dan atribut yang sesuai.
- Penyebab galat: Pengaturan struktur HTML dan validasi formulir perlu disesuaikan.
- Perbaikan yang dilakukan: Merapikan struktur HTML, menggunakan elemen formulir sesuai fungsinya, serta menambahkan atribut validasi.
- Hasil pengujian ulang: Elemen formulir berhasil disusun dan dapat digunakan untuk memasukkan data pengguna.
